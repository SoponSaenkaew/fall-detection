# 💻 IoT Dashboard (Next.js)

ส่วนหน้าจอผู้ใช้งานสำหรับตรวจสอบสถานะอุปกรณ์แบบ Real-time และปรับแต่งค่าเซนเซอร์

## ✨ คุณสมบัติ
- **Real-time Monitoring**: ดูสถานะล่าสุดของอุปกรณ์
- **Device Configuration**: ปรับค่า Threshold และระยะการติดตั้งเซนเซอร์ผ่านหน้าเว็บ
- **Responsive Interface**: ใช้งานได้ทั้งบน Desktop และ Mobile
